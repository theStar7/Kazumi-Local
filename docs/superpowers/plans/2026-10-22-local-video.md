# Windows 本地视频实施计划

基线：Kazumi 2.4.1（db5202611902fe67c449e0a53bc05c3a75b4e8b0）。

1. 本地视频数据与导入：独立 Hive 存储；多选文件与文件夹递归扫描；路径去重；同目录自然排序；验证持久化和原文件保护。
2. Windows 本地页面：导航入口、导入状态、视频列表、播放入口、移除和清除弹幕关联；验证导航索引与其他平台兼容。
3. 本地播放来源：复用现有播放器和同目录列表；独立进度记录；隔离在线番剧、评论、下载、投屏和一起看。
4. 弹幕关联：复用搜索与选集；每文件保存分集 ID；恢复关联；失败不覆盖；取消旧请求，验证切换与退出竞争。
5. 生成必要代码，运行 analyze/test 和 Windows 编译检查；记录确切验证结果并补充中文使用说明。

只交付源码，不打包、不发布。第一版不包含文件监听、番剧自动识别、拖放或离线弹幕缓存。

源码实施已完成。实际通过的检查、环境阻断及待运行验收项目见 [验证记录](../../LOCAL_VIDEO_VERIFICATION.md)，使用方法见 [Windows 本地视频](../../WINDOWS_LOCAL_VIDEO.md)。
